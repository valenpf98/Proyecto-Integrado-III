# Proyecto-Integrado-III

Este repositorio contiene la solución a la **Actividad 1: obtener y preparar datos desde Hugging Face**, desarrollada en Codespaces sobre GitHub.

## 📂 Contenido
- `src/clases_po/hf_loader.py` → Clase para cargar un dataset desde Hugging Face y devolverlo como DataFrame.
- `src/clases_po/reportes.py` → Clase para generar un resumen del DataFrame en un archivo `.txt`.
- `src/sincronicas/Semana_1SINC.ipynb` → Notebook que coordina el flujo completo: carga, transformación mínima y resumen.
- `src/sincronicas/datos/` → Carpeta donde se guardan los datos generados.
- `src/sincronicas/reportes/workout-routine.txt` → Archivo de reporte generado automáticamente con el resumen del DataFrame transformado.

## 📊 Dataset utilizado
Se emplea el dataset **workout-routine** disponible en Hugging Face, que contiene rutinas de entrenamiento.  
Este dataset permite practicar la carga de datos reales y aplicar transformaciones básicas para su análisis.
